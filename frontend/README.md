# Frontend - MC-03 Seguimiento Neonatal

Interfaz React + Vite con estilos Tailwind para el dashboard de cumplimiento neonatal.

## Instalación

```powershell
cd frontend
npm install
```

## Ejecución

```powershell
npm run dev
```

El frontend hace proxy a `http://127.0.0.1:8000/api` para consumir la API del backend.
